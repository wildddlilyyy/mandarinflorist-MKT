建議修改方向

  1. 優先處理非 200 頁面，修正 404、伺服器錯誤或不必要的轉址，避免搜尋引擎浪費爬取資源。
  2. 補齊缺少的 title 與 meta description，讓搜尋結果摘要更完整，也方便後續關鍵字布局。
  3. 確認每頁有清楚且唯一的 H1，並檢查 canonical 是否正確指向主要網址。
  4. 為重要圖片補上具描述性的 alt 文字，強化圖片 SEO 與無障礙體驗。
  5. 增加內容相關頁面的內部連結，提升網站結構清楚度與頁面權重傳遞。
  6. 分數較低或優先順序為「緊急／高」的頁面，建議先列入第一波修正清單。
