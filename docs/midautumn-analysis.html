四、資料口徑說明

  1. 統計範圍：2026/08/19 00:00 ~ 2026/09/30 23:59（台北時間）。
  2. 已排除狀態為 cancelled 的訂單，共 148 筆有效訂單納入統計。
  3. 商品銷售排行（第一節）採商品層級 subtotal_items 加總；顧客消費金額（第二、三節）一律採訂單層級 total（SHOPLINE Admin Open API 實際成交金額），兩者口徑不同——total 已扣除折扣、購物金、運費等，subtotal_items 為商品原價小計加總，兩者之間存在差異，不可直接相加比對。
  4. 商品單價欄為「總銷售金額 ÷ 銷量」之加權平均，非單一牌價。
  5. 回購率僅反映本檔期內之重複購買行為，非顧客終身回購率。
  6. 商品銷售件數（176件）為全期間所有訂單內 subtotal_items.quantity 加總，口徑與「有效訂單數」「顧客總數」一致（已排除 cancelled 及範圍外的 8/18 訂單）。
